# Kingyo (金魚)

Rize3xEXPOというアートイベントに参加した際のインタラクティブアート作品，映像は[![こちら](https://youtube.com)](https://youtu.be/iLshNIkqtzw)

## 概要

**Kingyo** は、ユーザーのタッチ/クリックインタラクションに反応して、画面内を泳ぐ金魚のパーティクル表現が生まれ、消滅するインタラクティブアート作品です。複数のデバイス（タッチパネルとラップトップなど）からのリアルタイム連携により、共有スペースでの没入感のある体験を実現します。

## 仕様

### コアシステム

#### 1. **p5.js ベースの金魚シミュレーション** (`sketch.js`)
- **パーティクルアニメーション**: ユーザーのインタラクション時に、指定座標から一定数のパーティクルが生成されます
- **画像ベース金魚モデル**: 2種類の金魚画像（左向き・右向き）から頂点データを自動抽出し、パーティクルで金魚の形状を再現
- **物理演算**: 
  - パーティクル同士の衝突検出と反発力計算
  - グリッドベースの最適化により、O(n²)の計算量を削減
  - ダンピング効果により現実的な動きを実現
- **ジオメトリックパターン**: マスク機能により、金魚の形状内に三角形・ストライプ・ドット・波模様などを動的に描画

#### 2. **金魚の動き**
- **自動移動**: 画面内を往復しながら泳ぎ、壁に衝突すると左右反転
- **身体の変形**:
  - **尾**: 時間とともに蛇行する動き
  - **背鰭**: 背中の上下動
  - **腹鰭**: 腹部の上下動
  - **頭**: 固定的な表現
- **速度バリエーション**: 3秒サイクルで異なる速度で泳ぐ（加速・減速・停止）
- **波状の揺らぎ**: 移動中にサイドスウェイの効果を追加

#### 3. **サウンドシステム**
- **衝突音**: パーティクル同士の衝突強度に応じて、周波数が動的に変わるシンセサウンド
- **水音エフェクト**: ユーザーのタップ時に複数の水滴音をランダムに再生
- **オーディオコンテキスト管理**: 音声再生エラーを防ぐため、定期的にオーディオコンテキストをリセット

#### 4. **リップル効果** (`Ripple` クラス)
- ユーザーインタラクション時に、タップ位置を中心に円形の波紋が展開
- 波紋はパーティクルの動きに影響を与え、より動的な表現を実現

#### 5. **ディケイ機能**
- 一定時間（15秒）インタラクションがない場合、金魚が徐々にフェードアウト
- 次のインタラクション時に新しい金魚が生成される
- パターンアルファ値が段階的に低下

### UI/UX

#### メインディスプレイ (`kingyo.html`)
```
┌────────────────────────────────┐
│                                │
│    [p5.jsキャンバス]            │
│    金魚パーティクル表示          │
│                                │
│    [木枠オーバーレイ]            │
│    17個の線要素で装飾            │
│    ↑壁に障子に模した木枠作成     │
└────────────────────────────────┘

```

- **背景**: ダークブルー (#080b29) にヘキサゴンパターン
- **木枠デザイン**: 中央の太い縦線と複数の区切り線で、日本的な視覚構成
  - 上部 (0-30%): 4本の縦線
  - 中部 (20-80%): 8本の縦線と2本の横線
  - 下部 (80-100%): 8本の縦線
- **リロード機能**: 40秒ごとに自動リロード（前4秒間は通知表示）

#### タッチパネル (`index.html`)
- シンプルなタッチ入力インターフェース
- WebSocket経由でメインディスプレイとリアルタイム連携
- ステータス表示により接続状態を可視化

### ネットワーク連携

#### WebSocket通信
```
[タッチパネル (client.js)] 
        ↓ (tap: {x, y, isNormalized})
 [WebSocketサーバー (ポート8080)]
        ↓
[メインディスプレイ (sketch.js)]
```

- **正規化座標**: タッチパネルの座標 (0.0 ~ 1.0) で正規化して送信
- **スケーリング**: メインディスプレイ側で画面サイズに自動スケール
- **遅延処理**: WebSocket受信後、50ms遅延してインタラクション実行（同期効果向上）

### パフォーマンス最適化

1. **グリッドベース衝突検出**
   - セルサイズ 14px でパーティクルを分割管理
   - 隣接セル (9方向) のみを検査

2. **キャッシング戦略**
   - パターンと金魚形状のマスクを分離キャッシュ
   - 形状が変わらない場合は再描画をスキップ

3. **一時ベクトル再利用**
   - クラス内で計算用ベクトルを確保し、都度生成を避ける

4. **フレームレート最適化**
   - フレームレート: 120 FPS
   - 画像サンプリング: 20px 間隔

## 主要クラス

### `MasterGoldfish`
金魚全体を管理するクラス。パーティクル群の生成・更新・衝突検出・レンダリング、および金魚の移動・変形を統括します。

### `Particle`
個別のパーティクルを管理。位置、速度、加速度、目標位置を持ち、フォロー動作と減衰を実装します。

### `Ripple`
波紋を管理。タップ位置を中心に拡大し、周辺パーティクルに影響を与えます。

## インタラクションフロー

1. ユーザーがタッチパネルをタップ
2. `client.js` が正規化座標をWebSocket経由で送信
3. `sketch.js` の `triggerKingyoInteraction()` が呼び出され:
   - パーティクル 28 個を生成
   - リップル効果を追加
   - 水音を再生
4. `MasterGoldfish` がパーティクルを更新し、リアルタイム描画

## セットアップ

### 必要な環境
- WebSocket サーバー (ポート 8080 で起動)
- p5.js ライブラリ (CDN から自動読み込み)
- モダンブラウザ (WebSocket / ES6 対応)

### 起動方法
1. メインディスプレイで `kingyo.html` を開く
2. タッチパネルで `index.html` を開く
3. WebSocket サーバーをポート 8080 で起動
4. タッチパネルからインタラクション実行
